# Awesome Grist Widgets

A Grist widget is a custom application that integrates with Grist to visualize, edit, or interact with your data.

> This is a curated collection of widgets for **Grist**.

Whether you're looking for charts, calendars, AI assistants, maps, Kanban boards, or developer tools, this repository helps you discover the best widgets built for the Grist ecosystem.

## Contributing

Contributions are welcome!

If you've built a widget—or know of a great one—you can submit it by opening a Pull Request.

Before submitting, please make sure your widget:

* Is publicly accessible.
* Includes a README with installation instructions.
* Has a clear license.
* Works with recent versions of Grist.
* Is maintained and functional.

Please read [CONTRIBUTING.md](CONTRIBUTING.md) before opening a Pull Request.

## Quality Guidelines

This repository is curated.

Not every submitted widget will necessarily be included. The goal is to maintain a high-quality collection of useful, well-maintained widgets for the Grist community.
